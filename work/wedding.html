속보 청첩장

뉴스 속보처럼 터뜨리는 모바일 청첩장

역할
기획 · 개발 · 배포
유형
개인 프로젝트 (친구 청첩장)
스택
HTML · CSS · JavaScript (라이브러리 없음)
구성
파일 1개 · 1,200줄
링크
happy-wook-kim.github.io/wedding-congrats

친구 결혼 소식을 그냥 알리기 아까워서 만들었습니다. 버튼을 누르면 속보가 터지듯 폭죽과 축하 멘트가 쏟아지고, 그다음에 청첩장이 열립니다. 빌드 도구도 프레임워크도 쓰지 않고 HTML 파일 하나로 만들어, 링크만 있으면 어디서든 열립니다.

Why

IDEA

청첩장을 여는 순간을 만들기

모바일 청첩장은 대개 열면 바로 정보가 나옵니다. 누르기 전까지 감추고, 누르는 순간 터지게 해서 소식을 전하는 장면을 만들었습니다.

NO BUILD

파일 하나, 의존성 없음

npm 설치도 빌드도 없습니다. HTML 하나에 스타일과 스크립트가 다 들어 있어 GitHub Pages에 올리면 끝입니다.

HANDMADE

약도를 SVG로 직접

지도 API를 붙이면 로딩도 느리고 키 관리도 생깁니다. 필요한 길과 역만 남겨 SVG로 그렸습니다. 가볍고, 볼 것만 보입니다.

DETAIL

연출에 들어간 것들

폭죽·꽃가루·부케 낙하, 축하 멘트 말풍선, 하단 속보 티커, 사진 라이트박스, 배경음 토글. 라이브러리 없이 CSS 애니메이션과 캔버스로 만들었습니다.

FALLBACK

안 되는 환경까지 계산

계좌 복사는 카카오톡 인앱 브라우저에서 클립보드가 막히는 경우가 있어 구식 방법으로 넘어가게 했습니다. 청첩장은 대부분 메신저로 열리니까요.

Screens

1 · 게이트

누르기 전까지는 아무것도 보여주지 않습니다

누르면 터집니다 — 폭죽, 축하 멘트, 속보 티커

3 · 약도

약도는 지도 API 없이 SVG로 그렸습니다
