뽑기 — 랜덤 추첨 게임

오늘 저녁값, 누가 쏠까? 한 화면에 모여서 하는 캐주얼 추첨 게임

역할
기획 · 개발 · 배포
유형
개인 프로젝트
스택
React 19 · TypeScript · Vite
구성
미니게임 5종 · 랜덤/점수 대결
링크
happy-wook-kim.github.io/bbobgi

"오늘 저녁값 누가 쏠까?" 같은 사소한 내기를, 한 화면에 모여서 정하는 캐주얼 랜덤 추첨 게임입니다. 카드 뽑기·룰렛·사다리타기·경마·주사위 5종을 직접 기획하고, 각 게임의 애니메이션과 연출까지 손수 구현했습니다. 다섯 게임을 셔플해 뽑는 랜덤 모드와, 목표 점수를 먼저 채우는 점수 대결 모드도 있습니다.

지금 바로 플레이 ↗

Highlights

MADE IT

기획부터 제작까지 직접

아이디어부터 5종 게임, 애니메이션·연출까지 직접 기획하고 만들었습니다.

INTERACTION

살아 있는 연출

룰렛 보너스 스핀, 경마의 돌·부스터 아이템, 원형 주사위 아레나의 카운트다운 강타까지 디테일을 살렸습니다.

MODES

게임 모드 설계

다섯 게임을 셔플한 '가방'에서 하나씩 꺼내는 랜덤 모드, 목표 점수 대결 모드까지 규칙을 직접 설계했습니다.

STACK

최신 프론트엔드

React 19 · TypeScript · Vite로 만들고, 테스트(vitest)로 핵심 로직의 안정성을 확보했습니다.
