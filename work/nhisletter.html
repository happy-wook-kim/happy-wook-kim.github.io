Case study

국민건강보험공단 명절카드

국민이 직접 만들어 보내는 공식 명절 인사 카드

역할
개발 · 인프라 · 배포 · 운영
클라이언트
국민건강보험공단
유형
공식 캠페인 웹사이트
스택
React 19 · TypeScript · Vite · PHP · MySQL · nginx
운영 기간
2026.9.16 ~ 9.30 (15일)
도메인
nhisletter.kr (운영 종료)

카드를 고르고 문구를 넣으면 그 자리에서 이미지로 합성돼, 저장하거나 카카오톡으로 보낼 수 있는 사이트입니다. 화면 개발만이 아니라 서버 구축부터 도메인·HTTPS·배포 자동화·부하 대비·운영 모니터링까지 혼자 맡았습니다. 2만명 대상 발송을 서버 오류 없이 넘겼고, 캠페인이 끝날 때까지 15일간 한 번도 멈추지 않았습니다.

In production

RESULT

저장·공유 6,528건

국민이 직접 문구를 써서 만든 카드입니다. 저장 4,075건, 카카오톡 공유 2,453건.

CONVERSION

들어온 사람의 49%

홈 화면 진입 13,276회 중 절반가량이 카드를 완성해 저장하거나 공유까지 갔습니다.

PEAKS

두 번 몰렸습니다

발송일 하루에 저장의 49%, 추석 직전 9/23~25 사흘에 33%. 명절 인사를 실제로 보내는 시점에 한 번 더 몰렸습니다.

SCALE

발송 당일 8.8만 요청

하루 45.5GB, 피크는 분당 4,182건. 가장 몰린 순간에도 서버 오류(5xx)는 단 한 건도 없었습니다.

UPTIME

15일 무중단

전 기간 20만 요청. 서버 재시작 0회, 메모리 부족 0건, 서버 오류 0건.

PERFORMANCE

방문자당 1.8MB

2만명이 한꺼번에 들어올 것을 계산해, 전달받은 9MB 애니메이션 카드를 목록용 정지 이미지로 따로 만들었습니다. 그대로였다면 120GB가 나갔을 트래픽입니다.

MOBILE

이용자 98.6%가 모바일

Android 64%, iPhone 34%. 대부분 문자와 카카오톡 안에서 열렸습니다.

OWNERSHIP

서버부터 정리까지 혼자

클라우드 인스턴스, HTTPS, 배포 스크립트, 요청 제한, 정리 자동화를 직접 구성했고 종료 후 정리까지 마쳤습니다.

Problem solving

01

카카오톡에서 저장이 안 되던 문제

카카오톡 인앱 브라우저는 일반적인 방식의 이미지 저장을 지원하지 않습니다. 다운로드가 시작되는 것처럼 보이다 조용히 사라졌습니다. 원인을 찾아 서버가 직접 파일을 내려주는 방식으로 바꿨습니다. 카카오톡으로 들어온 이용자들이 그 뒤로 정상 저장했습니다.

02

9MB 애니메이션 카드

클라이언트가 전달한 움직이는 카드가 9MB였습니다. 카드를 고르는 목록에서까지 원본을 받을 이유가 없어, 첫 프레임을 뽑아 정지 이미지를 따로 만들었습니다. 결과 화면에서는 원본 그대로 움직입니다.

03

같은 순간에 만든 카드가 섞이던 문제

파일 이름이 밀리초까지만 달라, 동시에 저장한 두 사람의 카드가 서로 덮어써질 수 있었습니다. 남의 인사말이 전달될 수 있는 문제라 이름 규칙부터 바로잡았습니다.

04

발송 전 부하 대비

2만명이 몰릴 상황을 계산해 서버 사양·동시 처리량·요청 제한을 미리 조정했습니다. 실제 피크는 분당 4,182건이었고 여유 있게 넘겼습니다.

05

한 번도 돌지 않던 정리 작업

오래된 파일을 지우는 예약 작업이 서버에 cron 이 없어 한 번도 실행되지 않고 있었습니다. 운영 중에 찾아내 systemd 타이머로 옮겼고, 그 뒤로 내려받기용 임시 파일은 하루 넘게 쌓이지 않았습니다.

06

카드별 공유 수를 역산

DB에는 카드 번호가 남지 않았습니다. 서버에 남은 공유 이미지 1,271장을 원본 카드와 대조해 분류했습니다. 1번 1,048 · 2번 212 · 3번 약 1,182.

07

이모지가 2자로 세지던 문제

글자 수를 코드 단위로 세서 🎉 가 2자, 가족 이모지는 8자로 잡혔습니다. 사람이 보는 글자 단위로 세도록 바꿔 50자 한도를 정확히 맞췄습니다.

08

끝난 뒤 정리

종료 후 집계 기록을 백업하고, 이용자가 쓴 문구가 담긴 이미지는 서버와 함께 지웠습니다. 클라우드 자원도 남김없이 정리해 비용이 더 나가지 않게 했습니다.

국민건강보험공단 공식 사이트로, 2026년 추석 캠페인(9/16~9/30) 동안 운영했습니다.
